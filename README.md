# Sistema-Cine-Matriz
Sistema de administración de asientos para cine basado en matrices

Integrantes: Victor Cristiano Alvarez Garcia 
matricula:24779407
 
 Descripción: Un cine desea automatizar y digitalizar por completo el proceso de administración de asientos para evitar los errores humanos comunes en las reservaciones manuales (como la             sobreventa, duplicidad de lugares o la pérdida de control de la sala).  

Tecnologías Utilizadas:
-Lenguaje de programación: Python o csharp/visual studio.
-Estructura de datos: Matrices bidimencinales.
-Entorno de desarrollo: Visual studio code o visual studio 2022.
-control de versiones: Git y GitHub.

Instrucciones de ejecucion:

1.clonar el repositorio: abre la terminal y ejecuta el siguiente comando para descargar el proyecto en tu computadora:

git:clon https://github.com/tu usuario/el nombre de tu repositorio.git

2.Abrir el proyecto:
abre la carpeta del proyecto clonado utilizando Visual Studio code o visual Studio.

3. Ejecutar el programa:
si estas utilizando Python, abre la terminal integrada dentro de la carpeta "CodigoFuente/" y ejecuta:
python cine.py

si estas utlzando csharp, abre el archivo de solucion(.sln) en visual studio y presiona el boton de iniciar (F5).

4. Interactuar con el sistema:
sigue las instrucciones en pantalla para navegar por el menu, consultar la matriz de asientos, realizar reservaciones o liberar lugares.
